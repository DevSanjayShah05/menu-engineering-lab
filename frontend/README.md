# Menu Matrix — frontend

React + TypeScript + Vite dashboard for the Menu Matrix menu-engineering lab.

See the [project root README](../README.md) for the full write-up: concept,
data sources & methodology, architecture, and setup instructions for both the
backend and this frontend.

Quick start:

```bash
npm install
npm run dev      # http://localhost:5173, expects the API at :8000
```
